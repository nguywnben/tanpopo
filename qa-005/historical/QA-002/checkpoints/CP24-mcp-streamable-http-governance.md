**Baseline:** `40bba5b55c2da6fc00b107b315c9b3167fb20169`  
**Runtime:** fresh isolated SQLite Tanpopo at `127.0.0.1:18086`; disposable MCP fixture at `127.0.0.1:19109`; Chromium via Playwright with screenshots visually inspected.  
**Implementation changes:** none. `GATE-REL-07`: **BLOCKED**.

## Scope and result

Scoped Streamable HTTP MCP lifecycle **PASS**: register a loopback server with explicit CIDR consent, discover and pin a tool schema, create a least-privilege MCP-only Virtual Key, grant the exact tool, initialize a real MCP session, list and invoke the tool, reject an ungranted tool, enforce plane isolation, lock execution on schema drift, recover after human pinning, and reject the revoked credential. This is one tested path; MCP side-effect classes, multi-tool behavior, other roles, non-loopback private networks, endpoint SSRF permutations, and concurrent in-flight revocation remain open.

3. Issued an MCP-only key constrained to exactly `qa002-cp24-server__echo_status`, granted that tool, and verified the SQLite grant/key records. Screenshots: `CP24-mcp-only-key-form.png`, `CP24-mcp-granted.png`; sanitized grant data: `CP24-mcp-grant.json`, `CP24-mcp-persistent-state.json`. Calling an ungranted tool returned JSON-RPC `tool_access_denied`; fixture recorded only one call. 5. Changed only the synthetic fixture schema by adding optional `audience`, then synced through the Console. The observed JCS hash changed to `10d22b76c1339087403769dd906c9bd421a6a86584ac69148ccf3958804f224a`; UI visibly showed `Schema Drift Locked`, `Drift locked`, and `Approve schema` (`CP24-mcp-sync-result.png`, visually inspected; `CP24-mcp-sync.json`). A real authorized tool call while locked returned JSON-RPC `schema_hash_drift_blocked`, and direct fixture state showed zero calls (`CP24-mcp-drift-blocked.json`).
6. Reviewed and pinned the changed schema using the real UI. Screenshot showed confirmation banner `Pinned schema hash and classified risk tier (read_only)`, `Active`, and `Pinned` with the changed hash (`CP24-mcp-schema-pinned.png`, visually inspected). Reusing the same secret for `initialize` returned HTTP 401 `invalid_virtual_key`; fixture call count remained one (`CP24-mcp-revoked-key-denial.json`). SQLite recorded `virtual_key.revoked`, key `REVOKED`, and retained no secret (`CP24-mcp-post-drift-persistent-state.json`).
