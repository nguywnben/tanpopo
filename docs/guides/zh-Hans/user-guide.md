# Tanpopo 用户指南

**Tanpopo** 是一款开源、自托管、单一二进制的 AI 网关与模型上下文协议（MCP）中心，专为确定性路由、只写凭据安全、精确微美元财务运维核算与离线可用运行而设计。

---

## 1. 快速开始与首次初始化

1. 启动 Tanpopo 服务器：
   ```bash
   tanpopo serve --role all --listen 127.0.0.1:8080
   ```
2. 首次启动时，Tanpopo 会在服务端日志中打印一次性**引导令牌（Bootstrap Token）**。
3. 在浏览器中打开 `http://127.0.0.1:8080/setup` 并完成 4 步初始化向导：
   - **所有者账号**：输入引导令牌、管理员邮箱、密码（至少 12 个字符）、组织名称与首个项目名称。
   - **首个连接（可选）**：接入商业 API 提供商（OpenAI、Anthropic、Google Gemini 或 OpenAI 兼容接口）或本地自托管推理引擎（vLLM、Ollama）。本地端点必须显式勾选允许内网访问，并填写精确的非通配 CIDR（如 `127.0.0.1/32`）。
   - **密钥保管**：确认已备份实例主加密密钥（Master KEK）。若丢失主密钥，密钥库中已加密的凭据将无法恢复。
   - **确认并初始化**：完成初始化，妥善保存仅展示一次的虚拟密钥，并发送首条流式测试请求完成验证。

## 2. 语言与外观

- **Web 控制台**：通过顶部栏（以及初始化和登录页面）的语言选择器切换显示语言。默认选中 **Auto**，按浏览器语言偏好自动匹配首个受支持的语言，无匹配项时回退至 English。手动选择会在刷新后保留，且随时可切回 **Auto**。
- **CLI 命令行**：通过 `--lang <代码>` 参数指定语言（例如 `tanpopo --lang zh-Hans --help`），或通过 `TANPOPO_LANG`、`LC_ALL`、`LC_MESSAGES`、`LANG` 环境变量自动识别。命令名、参数名与机器可读输出在所有语言下保持稳定。
- **API 错误与告警**：`/admin/v1/*` 控制平面接口根据 `Accept-Language` 请求头返回对应语言的 `error.message` 与告警摘要，同时保持 `error.code`、`error.type` 及 JSON 结构不变。
- **离线运行**：全部 15 种语言包、字体与图标均内嵌于单一二进制文件中，运行时产生 0 次外部 CDN 请求。

## 3. 控制台核心工作流

### 概览与请求追踪
- **概览**展示实时请求量、错误率、p95 代理开销、已结算微美元费用、活动预占、熔断已打开的部署以及附带处置入口的当前告警。
- **请求追踪**仅记录元数据遥测（绝不存储提示词或补全内容）。点击任意请求可查看分阶段耗时瀑布图与计量精度（精确、估算或未计量）。

### 提供商、模型与路由
- **提供商**：将 API 密钥、AWS IAM 凭据、Webhook HMAC 密钥或 TLS 证书封存到只写密钥库——明文仅单次上传，绝不回传。绑定协议适配器并执行实时连接探测。
- **模型与部署**：声明逻辑模型能力，并使用非负整数**纳美元（nano-USD）**费率卡将其绑定至提供商连接。
- **路由与策略**：配置确定性路由策略（优先级故障转移、加权分配、加权轮询、最低成本、最低延迟 EWMA）。通过**路由预演**在不产生上游流量或预算预占的前提下模拟路由决策。在组织、项目、环境三级配置单调收紧策略——子级只能收紧、不可放宽父级约束。

### 扩展、MCP 中心与调试台
- **扩展**：从离线缓存的扩展市场或通过固定摘要 URI + 64 位 SHA-256 暂存扩展包。激活前逐项审查权限差异，必要时可立即隔离受污染扩展并切断活动流。
- **MCP 中心**：注册 Streamable HTTP MCP 服务器、同步工具、固定 RFC 8785 JCS Schema 哈希、划分风险等级（`read_only`、`mutating`、`destructive`）并按工具粒度授权给虚拟密钥。
- **调试台**：使用带预算硬上限的临时会话密钥进行实时测试，对话仅存于当前标签页。支持一键复制 cURL、Python 与 TypeScript OpenAI SDK 代码片段。

### 访问控制、财务运维、安全中心与运维管理
- **访问与密钥**：签发环境级虚拟密钥、在 24 小时宽限期内轮换密钥，或通过优雅排空/紧急中止流吊销密钥。管理 6 角色 RBAC 权限分配。
- **财务运维**：实时追踪精确已结算费用、估算费用、活动预占与未计量请求；配置整数微美元预算硬上限并导出 CSV/JSON 成本分摊报表。
- **安全中心**：审批高危 MCP 工具调用的人工复核请求，触发或解除 4 级紧急熔断开关，并校验 RFC 8785 JCS 不可变审计哈希链。
- **运维管理（运维人员角色）**：查看 `/readyz` 就绪探针与集群快照纪元，创建 `.tpop.enc` 加密备份，执行升级 ABI 兼容性预检，并管理 HMAC 签名 Webhook。

## 4. CLI 常用命令速查

| 命令 | 说明 |
| --- | --- |
| `tanpopo serve` | 启动 Tanpopo 服务（`--role all`、`control-plane` 或 `data-plane`）。 |
| `tanpopo doctor` | 检查本地文件、数据库连接与服务健康状态（支持 `--output json`）。 |
| `tanpopo support-bundle` | 收集本地脱敏诊断包（绝不包含密钥库明文或提示词）。 |
| `tanpopo admin reset-local-owner` | 使用本地 Master KEK 文件离线重置组织所有者密码。 |
| `tanpopo backup create / verify / restore` | 创建、校验与原子恢复 `.tpop.enc` 加密备份。 |
| `tanpopo plugin init / validate / test / pack` | 开发、离线契约测试与打包可复现的 `.tpkg` 扩展包。 |
| `tanpopo upgrade preflight` | 升级 Tanpopo Core 前检查已安装扩展的 ABI 兼容性。 |
| `tanpopo key / route / budget / audit / killswitch` | 通过 `/admin/v1` 远程查看与运维控制平面资源。 |
