# Руководство пользователя Tanpopo

**Tanpopo** — это self-hosted AI-шлюз и хаб Model Context Protocol (MCP) в едином бинарном файле, созданный для детерминированной маршрутизации, защиты секретов в хранилище только на запись, точного учёта FinOps в micro-USD и автономной офлайн-работы.

---

## 1. Быстрый старт и первичная настройка

1. Запустите сервер Tanpopo:
   ```bash
   tanpopo serve --role all-in-one --listen 127.0.0.1:8080
   ```
2. При первом запуске Tanpopo выведет одноразовый **токен начальной настройки** (bootstrap token) в журнал сервера.
3. Откройте `http://127.0.0.1:8080/setup` в браузере и пройдите мастер из 4 шагов:
   - **Учётная запись владельца:** укажите токен запуска, email администратора, пароль (минимум 12 символов), название организации и первого проекта.
   - **Первое подключение (необязательно):** подключите коммерческого провайдера (OpenAI, Anthropic, Google Gemini или OpenAI-совместимый API) либо локальный движок (vLLM, Ollama). Для локальных адресов необходимо явно разрешить приватную сеть и указать конкретные CIDR без широких масок (например, `127.0.0.1/32`).
   - **Хранение ключа:** подтвердите, что вы сохранили резервную копию мастер-ключа шифрования (KEK). При утрате мастер-ключа зашифрованные секреты восстановить невозможно.
   - **Проверка и инициализация:** завершите настройку, надёжно сохраните одноразовый виртуальный ключ и проверьте первый потоковый запрос.

## 2. Язык и оформление

- **Веб-консоль:** используйте переключатель языка в верхней панели (или на страницах настройки и входа). По умолчанию выбран режим **Auto** — он автоматически подбирает первый поддерживаемый язык из предпочтений браузера с откатом к English. Ручной выбор сохраняется между перезагрузками, и вы всегда можете вернуться к **Auto**.
- **CLI:** передайте `--lang <код>` (например, `tanpopo --lang ru --help`) либо задайте `TANPOPO_LANG` / `LC_ALL` / `LC_MESSAGES` / `LANG`. Названия команд, флагов и машиночитаемые форматы вывода остаются неизменными.
- **Ошибки и оповещения API:** конечные точки `/admin/v1/*` учитывают заголовок `Accept-Language` для читаемых сообщений `error.message` и сводок оповещений, сохраняя стабильные `error.code`, `error.type` и JSON-схемы.
- **Офлайн-работа:** все 15 языков, шрифты и иконки встроены в бинарный файл — во время работы не выполняется ни одного внешнего CDN-запроса.

## 3. Основные рабочие процессы консоли

### Обзор и Трассы
- **Обзор:** показывает живой поток запросов, долю ошибок, накладные расходы p95, списанные затраты в micro-USD, активные резервы, развёртывания с разрывом цепи и активные оповещения со ссылками на устранение.
- **Трассы:** записывают телеметрию только по метаданным (тексты промптов и ответов не сохраняются). Нажмите на любой запрос, чтобы изучить таймлайн этапов и точность учёта (`Точно`, `Оценка`, `Без учёта`).

### Провайдеры, Модели и Маршрутизация
- **Провайдеры:** запечатывайте API-ключи, учётные данные AWS IAM, HMAC-секреты вебхуков и TLS-сертификаты в хранилище только на запись — открытый текст передаётся один раз и никогда не возвращается. Привязывайте адаптеры к upstream-адресам и запускайте живые проверки связи.
- **Модели и развёртывания:** объявляйте логические модели с возможностями и связывайте их с подключениями провайдеров с точными целочисленными тарифами в **nano-USD**.
- **Маршруты и политики:** настраивайте детерминированную маршрутизацию (`Приоритетный failover`, `Взвешенная`, `Взвешенный round robin`, `Минимальная стоимость`, `Минимальная задержка (EWMA)`). Используйте **Разбор маршрута** для dry-run симуляции без исходящего трафика и резервирования бюджета. Настраивайте монотонные политики на уровнях организации, проекта и среды — дочерний уровень может только ужесточать родительские ограничения.

### Расширения, MCP-хаб и Песочница
- **Расширения:** подготавливайте пакеты из локального офлайн-каталога или по URI с точным 64-символьным SHA-256. Проверяйте изменения прав перед активацией и немедленно помещайте скомпрометированные пакеты в карантин с разрывом активных потоков.
- **MCP-хаб:** регистрируйте Streamable HTTP MCP-серверы, синхронизируйте инструменты, фиксируйте хэши схем RFC 8785 JCS, назначайте класс риска (`read_only`, `mutating`, `destructive`) и выдавайте права конкретным виртуальным ключам.
- **Песочница:** тестируйте промпты с временным ключом сессии с жёстким лимитом бюджета — ключ и переписка остаются только в текущей вкладке. Копируйте готовые примеры на cURL, Python и TypeScript (OpenAI SDK).

### Доступ, FinOps, Безопасность и Операции
- **Доступ и ключи:** выпускайте виртуальные ключи среды, выполняйте ротацию с 24-часовым периодом совместимости или отзывайте ключи плавным дренажом либо аварийным разрывом потоков. Управляйте 6-ролевой моделью RBAC (`Оператор`, `Владелец орг.`, `Админ команды`, `Аудитор безоп.`, `Наблюдатель FinOps`, `Разработчик`).
- **FinOps:** контролируйте точные и оценочные расходы, активные резервы и неучтённые запросы; задавайте жёсткие лимиты в micro-USD и экспортируйте отчёты в CSV/JSON.
- **Безопасность:** рассматривайте HITL-одобрения для деструктивных вызовов MCP, активируйте или снимайте 4-уровневые Kill Switch и проверяйте целостность криптографической цепочки аудита RFC 8785 JCS.
- **Операции (роль `Оператор`):** отслеживайте готовность `/readyz` и эпохи снимков кластера, создавайте шифрованные резервные копии `.tpop.enc`, запускайте предпроверку обновлений и регистрируйте вебхуки с подписью HMAC.

## 4. Краткий справочник CLI

| Команда | Назначение |
| --- | --- |
| `tanpopo serve` | Запуск сервера Tanpopo (`--role all-in-one`, `control-plane`, `data-plane` или `worker`). |
| `tanpopo doctor` | Проверка бинарного файла, подключения к БД и прав хранилища (поддерживает `--json`). |
| `tanpopo support bundle` | Сбор очищенного диагностического архива (никогда не включает секреты и промпты). |
| `tanpopo admin reset-owner` | Офлайн-сброс пароля локального владельца организации (требует `--yes-i-know-this-resets-owner-password`). |
| `tanpopo backup create / restore` | Создание или восстановление шифрованной резервной копии `.tpop.enc`. |
| `tanpopo plugin install / upgrade / rollback / quarantine` | Управление расширениями с фиксацией дайджеста из CLI. |
| `tanpopo upgrade preflight` | Проверка совместимости ABI установленных расширений перед обновлением Tanpopo Core. |
| `tanpopo keys / routes / audit / kill-switch` | Управление удалёнными ресурсами Control Plane через `/admin/v1`. |
