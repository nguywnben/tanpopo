# Tanpopo ユーザーガイド

**Tanpopo** は、決定的なルーティング、書き込み専用の資格情報保護、厳密なマイクロ USD 単位の FinOps 会計、完全オフライン動作を備えた、単一バイナリのセルフホスト AI ゲートウェイ兼 Model Context Protocol（MCP）ハブです。

---

## 1. クイックスタートと初期セットアップ

1. Tanpopo サーバーを起動します：
   ```bash
   tanpopo serve --role all --listen 127.0.0.1:8080
   ```
2. 初回起動時、サーバーログに一度限りの**ブートストラップトークン**が出力されます。
3. ブラウザーで `http://127.0.0.1:8080/setup` を開き、4 ステップのセットアップを完了します：
   - **オーナーアカウント：** ブートストラップトークン、管理者メールアドレス、パスワード（12 文字以上）、組織名、初期プロジェクト名を入力します。
   - **初回接続（任意）：** 商用 API（OpenAI、Anthropic、Google Gemini、OpenAI 互換）またはローカル推論エンジン（vLLM、Ollama）を接続します。ローカル接続時はプライベートネットワーク許可と個別 CIDR（例：`127.0.0.1/32`）の指定が必要です。
   - **鍵の保管：** インスタンスのマスター暗号鍵（Master KEK）をバックアップ済みであることを確認します。紛失するとボールト内の暗号化認証情報は復号できません。
   - **確認と初期化：** セットアップを完了し、一度だけ表示される仮想キーを安全に保存して、初回ストリーミングテストを実行します。

## 2. 言語と外観

- **Web コンソール：** 上部バー（およびセットアップ・サインイン画面）の言語セレクターから切り替えます。既定の **Auto** はブラウザーの優先言語から最初の対応言語を選び、該当がない場合は English を使用します。手動選択はリロード後も保持され、いつでも **Auto** に戻せます。
- **CLI：** `--lang <コード>`（例：`tanpopo --lang ja --help`）または `TANPOPO_LANG`、`LC_ALL`、`LC_MESSAGES`、`LANG` で指定します。コマンド名、フラグ名、機械可読出力は言語によらず一定です。
- **API エラーとアラート：** `/admin/v1/*` は `Accept-Language` ヘッダーに応じて `error.message` とアラート概要をローカライズし、`error.code`、`error.type`、JSON スキーマを安定して維持します。
- **オフライン動作：** 全 15 言語、フォント、アイコンがバイナリに同梱されており、実行時に外部 CDN へ一切アクセスしません。

## 3. コンソールの主要ワークフロー

### 概要とトレース
- **概要**では、リクエスト数、エラー率、p95 プロキシ遅延、確定マイクロ USD コスト、アクティブ保留、サーキットオープン中のデプロイ、対処リンク付きアラートを確認できます。
- **トレース**はメタデータのみを記録し、プロンプトや応答本文は一切保存しません。各リクエストをクリックすると実行ステージのウォーターフォールと計測精度（`厳密`、`推定`、`未計測`）を確認できます。

### プロバイダー、モデル、ルーティング
- **プロバイダー：** API キー、AWS IAM 認証情報、Webhook HMAC シークレット、TLS 証明書を書き込み専用ボールトへ封印します。アダプターを接続しライブプローブで疎通を確認します。
- **モデルとデプロイ：** 論理モデルの機能を宣言し、非負整数**ナノ USD** 単価表でデプロイを作成します。
- **ルートとポリシー：** 決定的なルーティング戦略（優先度フェイルオーバー、重み付け、重み付けラウンドロビン、最小コスト、最小レイテンシ EWMA）を設定します。**ルート検証**で外部通信なしのドライラン評価ができ、組織・プロジェクト・環境の階層ポリシーは下位ほど厳格化のみ可能です。

### 拡張機能、MCP ハブ、プレイグラウンド
- **拡張機能：** オフラインマーケットプレイスまたはダイジェスト固定 URI + 64 文字 SHA-256 でステージし、権限差分を確認してから有効化します。問題発生時は即座に隔離してストリームを切断できます。
- **MCP ハブ：** Streamable HTTP MCP サーバーを登録し、ツール同期・RFC 8785 JCS スキーマ固定・リスク分類（`read_only`、`mutating`、`destructive`）・仮想キー別の許可付与を行います。
- **プレイグラウンド：** 予算上限付き一時セッションキーで対話テストを行い、cURL・Python・TypeScript の OpenAI SDK スニペットをコピーできます。

### アクセス、FinOps、セキュリティ、運用
- **アクセスとキー：** 環境専用の仮想キー発行、24 時間猶予付きローテーション、グレースフルドレイン／緊急失効、6 種類の RBAC ロールを管理します。
- **FinOps：** 厳密・推定コスト、アクティブ保留、未計測リクエストを監視し、マイクロ USD 予算上限と CSV/JSON 出力を管理します。
- **セキュリティ：** 破壊的 MCP 呼び出しの HITL 承認、4 段階の緊急停止スイッチ、RFC 8785 JCS 監査ハッシュチェーンの整合性検証を行います。
- **運用（`OPERATOR` ロール）：** `/readyz` とクラスターエポック監視、`.tpop.enc` 暗号化バックアップ、アップグレード互換性事前確認、HMAC 署名 Webhook を管理します。

## 4. CLI コマンド早見表

| コマンド | 用途 |
| --- | --- |
| `tanpopo serve` | Tanpopo サーバーを起動（`--role all`、`control-plane`、`data-plane`）。 |
| `tanpopo doctor` | ローカルファイル・DB・サービス健全性を診断（`--output json` 対応）。 |
| `tanpopo support bundle` | 機密除去済みの診断アーカイブを作成（平文シークレット・プロンプト除外）。 |
| `tanpopo admin reset-owner` | ローカル組織オーナーのパスワードをオフラインで再設定。 |
| `tanpopo backup create / verify / restore` | `.tpop.enc` 暗号化バックアップの作成・検証・復元。 |
| `tanpopo plugin init / validate / test / pack` | 拡張機能の作成・オフライン契約テスト・`.tpkg` パッケージ作成。 |
| `tanpopo upgrade preflight` | Tanpopo Core 更新前の ABI 互換性検証。 |
| `tanpopo key / route / budget / audit / killswitch` | `/admin/v1` 経由でリモートコントロールプレーンを操作。 |
