# Tanpopo 使用者指南

**Tanpopo** 是一款開源、自架優先、單一執行檔的 AI 閘道與模型上下文協定（MCP）中樞，專為決定性路由、唯寫密鑰安全、精確微美元財務維運帳務與離線運作而設計。

---

## 1. 快速入門與初次設定

1. 啟動 Tanpopo 伺服器：
   ```bash
   tanpopo serve --role all --listen 127.0.0.1:8080
   ```
2. 初次啟動時，Tanpopo 會在伺服器日誌印出一次性**引導權杖（Bootstrap Token）**。
3. 於瀏覽器開啟 `http://127.0.0.1:8080/setup` 並完成 4 步驟設定精靈：
   - **擁有者帳號**：輸入引導權杖、管理員電子郵件、密碼（至少 12 個字元）、組織名稱與首個專案名稱。
   - **首個連線（選用）**：連接商業 API 供應商（OpenAI、Anthropic、Google Gemini 或 OpenAI 相容介面）或地端自架引擎（vLLM、Ollama）。地端端點必須明確勾選允許私有網路存取，並列出精確的非萬用 CIDR（例如 `127.0.0.1/32`）。
   - **金鑰保管**：確認已妥善備份執行個體主加密金鑰（Master KEK）。若遺失主金鑰，保險庫內已加密的憑證將無法復原。
   - **檢視並初始化**：完成設定，立即保存僅顯示一次的虛擬金鑰，並傳送首筆串流測試請求完成驗證。

## 2. 語言與外觀

- **Web 主控台**：使用頂部列（以及初次設定與登入頁面）的語言選擇器切換顯示語言。預設選項為 **Auto**，會依據瀏覽器偏好語系自動選取第一個支援語言，無符合項目時回退至 English。手動選擇會在重新整理後保留，並可隨時切回 **Auto**。
- **CLI 命令列**：使用 `--lang <代碼>` 旗標指定語系（例如 `tanpopo --lang zh-Hant --help`），或透過 `TANPOPO_LANG`、`LC_ALL`、`LC_MESSAGES`、`LANG` 環境變數自動判斷。指令名稱、旗標名稱與機器可讀輸出於各語系下維持一致。
- **API 錯誤與警示**：`/admin/v1/*` 控制平面端點依 `Accept-Language` 標頭回傳對應語系的 `error.message` 與警示摘要，同時保留穩定的 `error.code`、`error.type` 與 JSON 結構。
- **離線運作**：全部 15 種語系、字型與圖示皆封裝於執行檔內，執行時期不產生任何外部 CDN 請求。

## 3. 主控台核心工作流程

### 總覽與請求追蹤
- **總覽**呈現即時請求數、錯誤率、p95 代理額外延遲、已結算微美元費用、作用中預扣、斷路器已開啟的部署，以及附帶處置連結的目前警示。
- **請求追蹤**僅紀錄中繼資料執行遙測（絕不儲存提示詞或補全內容）。點選任一請求即可檢視分階段耗時瀑布圖與計量精度（精確、估算或未計量）。

### 供應商、模型與路由
- **供應商**：將 API 金鑰、AWS IAM 憑證、Webhook HMAC 密鑰或 TLS 憑證封存於唯寫保險庫——明文僅單次寫入，永不回傳。繫結協定配接器並執行即時探測。
- **模型與部署**：宣告邏輯模型能力，並以非負整數**奈美元（nano-USD）**費率卡繫結至供應商連線。
- **路由與原則**：設定決定性路由策略（優先順序容錯移轉、權重分配、權重輪詢、最低成本、最低延遲 EWMA）。透過**路由預演**在不觸發上游流量或預算預扣的情況下模擬路由決策。在組織、專案與環境階層設定單調收緊原則——子階層只能收緊、不可放寬父階層限制。

### 擴充套件、MCP 中樞與測試環境
- **擴充套件**：從離線快取市集或透過固定摘要 URI + 64 位 SHA-256 暫存套件。啟用前逐項審核權限差異；必要時可立即隔離異常套件並切斷作用中串流。
- **MCP 中樞**：註冊 Streamable HTTP MCP 伺服器、同步工具、固定 RFC 8785 JCS Schema 雜湊、指定風險等級（`read_only`、`mutating`、`destructive`）並授權給特定虛擬金鑰。
- **測試環境**：以具備預算硬性上限的暫時性工作階段金鑰進行互動測試，對話僅保留於目前分頁，並提供即用型 cURL、Python 與 TypeScript OpenAI SDK 程式碼範例。

### 存取控制、財務維運、資安中心與維運管理
- **存取與金鑰**：核發環境限定虛擬金鑰、以 24 小時寬限期輪替金鑰，或以平順排空／緊急中斷串流方式撤銷金鑰。管理 6 角色 RBAC 權限指派。
- **財務維運**：監控精確已結算費用、估算費用、作用中預扣與未計量請求；設定整數微美元預算硬性上限並匯出 CSV/JSON 成本分攤報表。
- **資安中心**：審核高風險 MCP 工具呼叫的人工簽核請求、觸發或解除 4 層級緊急切斷開關，並驗證不可變 RFC 8785 JCS 稽核雜湊鏈。
- **維運管理（維運人員角色）**：檢視 `/readyz` 就緒探測與叢集快照紀元、建立 `.tpop.enc` 加密備份、執行升級 ABI 相容性前置檢查，並管理 HMAC 簽章 Webhook。

## 4. CLI 指令速查

| 指令 | 用途 |
| --- | --- |
| `tanpopo serve` | 啟動 Tanpopo 服務（`--role all`、`control-plane` 或 `data-plane`）。 |
| `tanpopo doctor` | 檢查本機檔案、資料庫連線與服務健康狀態（支援 `--output json`）。 |
| `tanpopo support-bundle` | 蒐集去識別化診斷封存包（絕不含保險庫明文或提示詞）。 |
| `tanpopo admin reset-local-owner` | 使用本機 Master KEK 檔案離線重設組織擁有者密碼。 |
| `tanpopo backup create / verify / restore` | 建立、驗證與原子還原 `.tpop.enc` 加密備份。 |
| `tanpopo plugin init / validate / test / pack` | 開發、離線契約測試與封裝可重現 `.tpkg` 擴充套件。 |
| `tanpopo upgrade preflight` | 升級 Tanpopo Core 前驗證已安裝擴充套件的 ABI 相容性。 |
| `tanpopo key / route / budget / audit / killswitch` | 透過 `/admin/v1` 遠端操作控制平面資源。 |
