# Tanpopo 사용자 가이드

**Tanpopo**는 결정적 라우팅, 쓰기 전용 자격 증명 보안, 정확한 micro-USD FinOps 회계, 오프라인 운영을 지원하는 셀프 호스팅 단일 바이너리 AI 게이트웨이 및 Model Context Protocol(MCP) 허브입니다.

---

## 1. 빠른 시작 및 초기 설정

1. Tanpopo 서버를 시작합니다:
   ```bash
   tanpopo serve --role all --listen 127.0.0.1:8080
   ```
2. 최초 실행 시 Tanpopo는 일회용 **부트스트랩 토큰**을 서버 로그에 출력합니다.
3. 브라우저에서 `http://127.0.0.1:8080/setup`을 열고 4단계 설정 마법사를 완료합니다:
   - **소유자 계정:** 부트스트랩 토큰, 관리자 이메일, 비밀번호(최소 12자), 조직 이름, 첫 프로젝트 이름을 입력합니다.
   - **첫 연결(선택):** 상용 API 프로바이더(OpenAI, Anthropic, Google Gemini 또는 OpenAI 호환)나 로컬 셀프 호스팅 엔진(vLLM, Ollama)을 연결합니다. 로컬 엔드포인트는 사설 네트워크 접근을 명시적으로 허용하고 와일드카드가 아닌 정확한 CIDR(예: `127.0.0.1/32`)을 지정해야 합니다.
   - **키 보관:** 인스턴스 마스터 암호화 키(KEK)를 백업했음을 확인합니다. 마스터 키를 분실하면 암호화된 볼트 시크릿을 복구할 수 없습니다.
   - **검토 및 초기화:** 설정을 완료하고 일회용 가상 키를 안전하게 보관한 뒤 첫 스트리밍 요청을 검증합니다.

---

## 2. 언어 및 화면 표시

- **웹 콘솔:** 상단 바(또는 설정·로그인 화면)의 언어 선택기를 사용합니다. 기본값은 **Auto**이며 브라우저 선호 언어 중 지원하는 첫 번째 언어를 선택하고 일치하는 항목이 없으면 English로 대체됩니다. 수동 선택은 새로고침 후에도 유지되며 언제든지 **Auto**로 되돌릴 수 있습니다.
- **CLI:** `--lang <코드>`(예: `tanpopo --lang ko --help`)를 전달하거나 `TANPOPO_LANG` / `LC_ALL` / `LC_MESSAGES` / `LANG` 환경 변수를 설정합니다. 명령 이름, 플래그 이름, 기계 판독 출력은 모든 언어에서 동일하게 유지됩니다.
- **API 오류 및 알림:** `/admin/v1/*` 컨트롤 플레인 엔드포인트는 `Accept-Language` 헤더를 반영하여 사람이 읽는 `error.message`와 운영 알림 요약을 번역하며 `error.code`, `error.type`, JSON 스키마는 안정적으로 유지합니다.
- **오프라인 운영:** 15개 언어, 글꼴, 아이콘이 모두 바이너리에 포함되어 실행 중 외부 CDN 요청이 전혀 발생하지 않습니다.

## 3. 주요 콘솔 워크플로

### 개요 및 트레이스
- **개요:** 실시간 요청 수, 오류율, p95 프록시 오버헤드, 정산된 micro-USD 비용, 활성 보류, 서킷 차단된 배포, 즉시 조치 링크가 포함된 활성 알림을 확인합니다.
- **트레이스:** 메타데이터 전용 실행 텔레메트리를 기록합니다(프롬프트나 응답 본문은 저장하지 않음). 요청을 클릭해 단계별 워터폴과 계량 정확도(`정확`, `추정`, `미계량`)를 검사합니다.

### 프로바이더, 모델 및 라우팅
- **프로바이더:** API 키, AWS IAM 자격 증명, 웹훅 HMAC 시크릿, TLS 인증서를 쓰기 전용 볼트에 봉인합니다. 평문은 한 번만 전송되며 다시 반환되지 않습니다. 어댑터를 업스트림 엔드포인트에 바인딩하고 실시간 프로브를 실행합니다.
- **모델 및 배포:** 논리 모델의 기능을 선언하고 음이 아닌 정수 **nano-USD** 요율표와 함께 프로바이더 연결에 바인딩합니다.
- **라우트 및 정책:** 결정적 라우팅 전략(`우선순위 페일오버`, `가중치`, `가중치 라운드 로빈`, `최저 비용`, `최저 지연(EWMA)`)을 구성합니다. **라우트 시뮬레이션**으로 업스트림 호출이나 예산 보류 없이 드라이런 테스트를 수행합니다. 조직·프로젝트·환경 단위의 단조 강화 정책을 설정할 수 있으며 하위 범위는 상위 제한을 더 엄격하게만 조정할 수 있습니다.

### 확장 기능, MCP 허브 및 플레이그라운드
- **확장 기능:** 오프라인 캐시 마켓플레이스나 64자리 SHA-256이 고정된 URI로 패키지를 스테이징합니다. 활성화 전 권한 변경 내역을 검토하고 승인하며, 문제가 생긴 패키지는 즉시 격리해 활성 스트림을 차단합니다.
- **MCP 허브:** Streamable HTTP MCP 서버를 등록하고 도구를 동기화하여 RFC 8785 JCS 스키마 해시를 고정합니다. 위험 등급(`read_only`, `mutating`, `destructive`)을 지정하고 특정 가상 키에 도구 권한을 부여합니다.
- **플레이그라운드:** 현재 탭에만 유지되고 예산 상한이 있는 임시 세션 키로 프롬프트를 대화형으로 테스트합니다. 바로 실행 가능한 cURL, Python, TypeScript OpenAI SDK 스니펫을 복사할 수 있습니다.

### 접근, FinOps, 보안 및 운영
- **접근 및 키:** 환경 단위 가상 키를 발급하고 24시간 유예 기간으로 교체하거나 정상 드레인 또는 긴급 스트림 중단으로 폐기합니다. 6개 역할 RBAC(`운영자`, `조직 소유자`, `팀 관리자`, `보안 검토자`, `FinOps 열람자`, `개발자`)를 관리합니다.
- **FinOps:** 정확 정산 비용, 추정 비용, 진행 중인 사전 보류, 미계량 요청을 모니터링합니다. 정수 micro-USD 예산 상한을 설정하고 CSV/JSON 비용 배분 보고서를 내보냅니다.
- **보안:** 파괴적 MCP 호출에 대한 HITL 승인을 검토하고 4단계 긴급 킬 스위치를 발동·해제하며 RFC 8785 JCS 감사 해시 체인의 무결성을 검증합니다.
- **운영(`운영자` 역할):** `/readyz` 준비 상태와 클러스터 스냅샷 에포크를 모니터링하고 암호화된 `.tpop.enc` 백업 생성, 업그레이드 호환성 사전 점검, HMAC 서명 웹훅 등록을 수행합니다.

## 4. CLI 주요 명령 요약

| 명령 | 용도 |
| --- | --- |
| `tanpopo serve` | Tanpopo 서버 실행 (`--role all`, `control-plane`, `data-plane`). |
| `tanpopo doctor` | 바이너리, 데이터베이스 연결 및 스토리지 권한 점검 (`--output json` 지원). |
| `tanpopo support-bundle` | 민감 정보가 제거된 진단 아카이브 수집(볼트 평문 및 프롬프트 제외). |
| `tanpopo admin reset-local-owner` | 로컬 조직 소유자 비밀번호 오프라인 재설정 (`--db` / `--email` 필요). |
| `tanpopo backup create / verify / restore` | 암호화된 `.tpop.enc` 백업 아카이브 생성 또는 복원. |
| `tanpopo bundle export / verify / import` | 다이제스트 고정 확장 기능을 CLI에서 관리. |
| `tanpopo upgrade preflight` | Tanpopo Core 업그레이드 전 설치된 확장 기능의 ABI 호환성 검증. |
| `tanpopo key / route / audit / killswitch` | `/admin/v1`을 통해 원격 컨트롤 플레인 리소스 운영. |
