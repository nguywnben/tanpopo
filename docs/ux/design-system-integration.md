## 2. Six Mandatory Astryx v0.7.13 Discipline Rules

1. **Zero Raw HTML Layout Tags (`Zero Raw div / span`):**
   - All layout, spacing, and text rendering must compose Astryx primitives (`AppShell`, `TopNav`, `SideNav`, `Layout`, `LayoutContent`, `LayoutPanel`, `Section`, `VStack`, `HStack`, `Grid`, `StackItem`, `Divider`, `Text`, `Heading`).
2. **Dense Operational Data = `Table` or `List` / `Item` (Never Card-Wrapped Lists):**
   - `Request Traces`, `Virtual Keys`, `Audit Events`, `Provider Connections`, `Model Deployments`, `Installed Plugins`, `MCP Tools`, and `Chargeback Rows` must render via `Table` (`useTableColumnSettingsState`) or `List` / `Item`. Reserve `Card` strictly for aggregate KPI summary tiles or standalone callouts.
3. **Strict `Badge` vs. `Token` Separation (`AGENTS.md` + `WCAG 2.2 AA`):**
   - **`Badge` = integer counts only** (e.g., pending HITL approval count on `SideNav`, active alert count, tool count per MCP server).
   - **States, trust tiers, and assurance levels = `Token` (`@astryxdesign/core/Token`)** paired with both `icon={<Icon icon="..." size="sm" />}` and a concise `label`.
4. **Props First, Semantic Tokens Second (`0` Raw `#hex` or Arbitrary `px`):**
   - Use component props (`padding`, `gap`, `variant`, `contentWidth`) first, then semantic CSS variables (`var(--color-*)`, `var(--spacing-*)`, `var(--radius-*)`). Never override `:root` colors or import custom `.css` overrides beyond the entry-point cascade (`reset.css` -> `astryx.css` -> `astryx-themes.js`).
5. **Scaffold Every Screen from Verified Astryx Templates:**
   - Every screen in `web/console/src/pages/*` starts from `npx @astryxdesign/cli template <id>` and passes `npx @astryxdesign/cli doctor --built dist` with `0 fail` in CI.
6. **Canonical 29 Built-In Semantic Icons Only (`@astryxdesign/core/Icon`):**
   - To guarantee `0` external icon CDN fetches and `0` unapproved icon package bloat, all UI status and action glyphs resolve strictly from `@astryxdesign/core/Icon`'s **29 built-in `IconName` entries** (`node_modules/@astryxdesign/core/dist/Icon/globalIconRegistry.d.ts`):
     `close`, `chevronDown`, `chevronLeft`, `chevronRight`, `chevronsLeft`, `chevronsRight`, `check`, `success`, `error`, `warning`, `info`, `calendar`, `clock`, `externalLink`, `menu`, `moreHorizontal`, `search`, `upload`, `arrowUp`, `arrowDown`, `arrowsUpDown`, `funnel`, `eyeSlash`, `viewColumns`, `copy`, `checkDouble`, `wrench`, `stop`, `microphone`.

## 5. Twelve Testable Usability & UI Quality Acceptance Criteria (`UX-AC-01` .. `UX-AC-12` — `TARGET / UNVERIFIED`)

| Criterion ID | Evaluation Dimension | Quantitative Pass Threshold (`TARGET / UNVERIFIED`) | Concrete Automated Verification Method |
|---|---|---|---|
| **`UX-AC-01`** | **Time to First Good Request (`TTFGR`)** | `<= 180 seconds` (`3 minutes` — `TARGET / UNVERIFIED`) from fresh `tanpopo serve` boot (including local `Ollama` with `allow_private_ip` consent) to `200 OK` SSE completion. | Timed Playwright E2E journey `UJ-01` calibrated to human input cadence with zero external docs. |
| **`UX-AC-02`** | **Mobile Emergency Kill-Switch Speed (`375px`)** | `<= 3` taps from any screen to open the Kill-Switch `AlertDialog`, completing key revocation in `< 15 seconds` (`TARGET / UNVERIFIED`) with `>= 44x44 CSS px` targets. | Playwright E2E test on `375x812` viewport asserting zero horizontal overflow obscuring action controls. |
| **`UX-AC-03`** | **Pre-Install Risk Transparency** | `100%` of `.tpkg` install and permission-escalating upgrade flows keep activation disabled until `Origin`, `Trust Tier`, `Allowed Hosts`, and `Secret Slots` render in full. | Automated UI test asserting `Approve & Activate` is disabled prior to opening the Permission Inspection Sheet. |
| **`UX-AC-04`** | **Zero Raw Secrets in DOM & Storage** | `0` upstream secret bytes in `/admin/v1/*` responses, DOM nodes, `localStorage`, or `sessionStorage`; show-once `Virtual Key` wiped immediately on dialog close. | Automated CanaryScanner sweep across DOM, Web Storage, and HAR network logs after creating/reloading `SCR-04` and `SCR-13`. |
| **`UX-AC-05`** | **Automated `WCAG 2.2 AA` & Multi-Viewport Parity** | `0` `critical` or `serious` `@axe-core/playwright` violations across all 16 screens in both Light & Dark modes and across all 4 viewport bands (`1440px`, `1152px` (`1024–1279px`), `834px`, `375px`). | Mandatory CI accessibility + keyboard-only (`Tab`/`Enter`/`Space`/`Escape`/Arrows) suite across Chromium, Firefox, and WebKit. |
| **`UX-AC-06`** | **Zero Color-Only Status Reliance** | `100%` of health, trust, MCP risk, and settlement-accuracy `Token` components pair a built-in `IconName` glyph with explicit accessible text. | Accessibility tree test asserting non-empty accessible names and distinct `icon` props on every status `Token`. |
| **`UX-AC-07`** | **Astryx Build Discipline (`astryx doctor --built`)** | `0 fail` from `npx @astryxdesign/cli doctor --built dist`; `0` raw `div`/`span` tags in `web/console/src`; `0` hardcoded `#hex` literals; `Badge` restricted strictly to integer counts. | Mandatory `Stage 3 CI` gate executed prior to embedding `web/console/dist` into the `tanpopo` binary. |
| **`UX-AC-08`** | **Frontend Performance & Bundle Budgets** | LAN profile (`TARGET / UNVERIFIED`): `LCP <= 2.0s`, `INP <= 150ms`, `CLS <= 0.05`; initial JS bundle `gzip <= 250 KB` via route-level code splitting and static StyleX CSS extraction. | Automated Lighthouse CI profiling against the production SPA served from the embedded `tanpopo` binary. |
| **`UX-AC-09`** | **High-Density Table & `100 tok/s` Stream Smoothness** | `200`-row cursor-paginated `Traces` / `Audit` tables keep filter/scroll `INP < 100ms` (`TARGET / UNVERIFIED`); `SCR-15` `Playground` renders `100 tokens/sec` (`TARGET / UNVERIFIED`) SSE streams without dropped frames. | Playwright performance benchmark against a `100,000`-row synthetic dataset and loopback SSE stream emitter. |
| **`UX-AC-10`** | **100% Air-Gap Ready UI (`Zero External Requests`)** | `0` browser requests to external domains (`0` requests to `https://fonts.googleapis.com`, `fonts.gstatic.com`, CDNs, or analytics) across all 16 screens. | Offline network-namespace Playwright suite failing on any non-`127.0.0.1` outbound request or failed font load. |
| **`UX-AC-11`** | **Non-Destructive `409 optimistic_lock_conflict` Diff UX** | Concurrent edit collisions on `Route` or `Policy` forms preserve the local draft and render a side-by-side diff against `error.current_resource` in `< 1 second` (`TARGET / UNVERIFIED`). | Dual-context Playwright E2E test verifying concurrent `If-Match` conflict recovery. |
| **`UX-AC-12`** | **Compliance & Capability Honesty** | `0` `"Official"`/`"Supported"` labels on consumer subscriptions (`DEC-004`); `100%` of unsupported capabilities surface pre-flight callouts or actionable remediation errors. | Automated content + OpenAPI contract test suite cross-checked against `UX-GR-02` and `UX-GR-03`. |
