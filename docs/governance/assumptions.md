## Part A — Unvalidated Working Hypotheses (`ASSUMED`)

> **Mandatory Warning for AI Agents and Engineers:** Every `ASSUMED` item below **awaits Product Owner approval and empirical PoC measurement**. Never present these targets as proven facts until Gates G1–G3 are approved and `SPIKE-01`..`04` (`TP-IMP-0004`) are executed and recorded.

| ID | Domain | Working Hypothesis | Status | Risk If Disproved | Validation Spike & Target ADR |
|---|---|---|---|---|---|
| **ASM-001** | Beachhead User Segment | Dual beachhead focus on **Dev Teams (5–50 engineers)** and **AI Platform Teams (50–500 engineers)** via a single binary supporting embedded standalone mode and stateless HA scale-out maximizes adoption velocity while deferring >1,000-seat regulated-enterprise certifications to `v1.0+`. | `ASSUMED` | Targeting only regulated enterprises makes embedded SQLite redundant; targeting only solo developers creates a hard scalability ceiling. | `SD-G1-01`, [`ADR-0003`](../architecture/adr/0003-dual-mode-persistence-and-cluster-state.md), `EXP-06`. |
| **ASM-002** | Streaming Traffic & Wasm Overhead | Data Plane traffic is dominated by long-lived SSE/chunked streams and MCP sessions, and `wazero` Wasm sandboxing can sustain `< 5 ms p95` request overhead and `< 1 ms/chunk` streaming latency without memory leaks on `2 vCPU / 2 GiB RAM`. | `ASSUMED` | Excessive Host–Wasm copy/call overhead (`RSK-004`) would require restricting Wasm hooks to request/response headers & final usage while keeping middle-of-stream chunk framing in Host native code. | **`SPIKE-02`** (`EXP-01` / `POC-01`), [`ADR-0002`](../architecture/adr/0002-three-tier-extension-sandbox-and-blind-broker.md). |
| **ASM-003** | Role of Pre-Installed Astryx Packages | Pre-installed `@astryxdesign/core`, `@astryxdesign/theme-neutral`, `@astryxdesign/cli`, and `@stylexjs/stylex` power the **static Web Console SPA** embedded into the Go binary, rather than dictating a Node.js/React runtime for the Gateway Core. | `ASSUMED` | If the Owner prefers a full-stack TypeScript runtime or a different UI stack, workspace layout changes significantly. | Evaluated independently in [`ADR-0001`](../architecture/adr/0001-core-runtime-and-modular-monolith.md) & [`ADR-0004`](../architecture/adr/0004-web-console-stack-astryx-evaluation-and-repo-layout.md). |
| **ASM-004** | Tier-1 Declarative Adapter Coverage | At least 75–80% of standard REST/SSE model providers can be expressed purely via Tier-1 Declarative manifests (`0` arbitrary code execution), leaving ~15–20% to Tier-2 Wasm and ~5% to Tier-3 Sidecars. | `ASSUMED` | If most providers require custom imperative code, extension authors face higher Wasm compilation friction (`RSK-005`). | **`SPIKE-01`** (`EXP-02`/`03`, `POC-02`), [`ADR-0002`](../architecture/adr/0002-three-tier-extension-sandbox-and-blind-broker.md). |
| **ASM-005** | Blind Host Credential Brokering | Upstream credentials can remain AEAD-sealed in the Host Vault and be injected/signed at the network egress boundary (`BlindHostCredentialBroker` + `HostCryptoSignSpec`) with `0` raw secret bytes ever entering Wasm plugin memory. | `ASSUMED` | Exotic proprietary signing schemes unsupported by Host primitives must run in operator-governed Tier-3 Sidecars (`CR-05`). | `SPEC-EXT-03`, [`ADR-0002`](../architecture/adr/0002-three-tier-extension-sandbox-and-blind-broker.md), **`SPIKE-02`**. |
| **ASM-006** | OpenTelemetry & Two-Phase `Micro-USD` Ledger | Fail-open bounded OTLP export paired with an integer `BIGINT micro-USD` two-phase reservation ledger (`Pre-Hold` + `Negative Balance Carryover`) prevents concurrent spend overruns without mid-sentence stream truncation. | `ASSUMED` | Overly conservative holds or slow orphan reaping could cause false `429 project_budget_exceeded` rejections under high concurrency (`RSK-007`). | [`ADR-0005`](../architecture/adr/0005-two-phase-budget-ledger-and-commercial-billing-separation.md), `SPEC-CORE-02`, **`SPIKE-03`** (`EXP-04`). |
| **ASM-007** | Admin-Only Extension Installation | Only authorized administrators (`OPERATOR`, `ORG_OWNER`, `SECURITY_REVIEWER`) can install, upgrade, or approve network/secret permissions for Extensions; `DEVELOPER` / API clients only consume enabled endpoints. | `ASSUMED` | Allowing arbitrary end-user code uploads per request would require microVM-grade multi-tenant isolation. | `ARCH-DATA-01` RBAC, `TP-FR-0502`, `CR-04`. |
| **ASM-008** | Repository-Wide Apache-2.0 Licensing | Root [`LICENSE`](../../LICENSE) (`Apache-2.0`, commit `0a35b74`) represents the Product Owner's intended open-source license for the entire self-hosted platform, whereas `"license": "ISC"` in [`package.json`](../../package.json) is an accidental `npm init -y` default. | `ASSUMED` | Choosing dual-license Open-Core would require physically separating commercial directories. | `SD-G1-05`, [`ADR-0004`](../architecture/adr/0004-web-console-stack-astryx-evaluation-and-repo-layout.md). |
| **ASM-009** | Solving the Marketplace Cold-Start Problem | Shipping 5 Official Reference Adapters in `v0.1` (`OpenAI`, `Anthropic`, `Gemini`, `OpenAI-Compatible/vLLM`, `Ollama` per `CR-01`) built on the exact public Extension Contract delivers 100% standalone day-one utility even with zero third-party plugins installed. | `ASSUMED` | Missing a critical enterprise provider in `v0.1` (`AWS Bedrock` / `Azure` scheduled for `v0.2` in `CR-01`) could slow cloud-native enterprise PoCs. | `CR-01`, `EXP-06`, **`SPIKE-01`**. |
| **ASM-010** | Static Signed Marketplace Index | Public extension discovery can operate via a signed static `index.json` + `revocations.json` on Git/CDN + OCI Registry artifacts at near-\$0/month hosting cost throughout `v0.x–v1.0`. | `ASSUMED` | Thousands of community packages may eventually require a lightweight search/indexing service post-`v1.0`. | `SPEC-EXT-04` ([`marketplace-lifecycle.md`](../specifications/marketplace-lifecycle.md)). |
