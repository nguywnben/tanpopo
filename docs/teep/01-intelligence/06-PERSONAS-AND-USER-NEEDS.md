## 1. Strategic Dual-Horizon Mandate: Zero-Friction Day-0 to Fortune 500 Day-100

Per the Founder's TEEP mandate, Tanpopo must succeed simultaneously across **two historically antagonistic user segments** without compromising architectural safety or splitting into incompatible codebases:
1. **First-Time Self-Hosted Users (`PER-01`, `PER-02`):** Require `< 90s` (`HYPOTHESIS / UNVERIFIED`) time-to-first-governed-token on a single laptop, homelab server, or Docker host with zero Kubernetes, zero ClickHouse, and zero manual `nano-USD` arithmetic.
2. **Sophisticated Enterprise & Regulated Organizations (`PER-03`..`PER-10`):** Require 7-tier organizational governance, secretless workload identity, SCIM/SAML/Cedar policy-as-code, `20,000+ RPS` (`HYPOTHESIS / UNVERIFIED`) multi-region resilience, cryptographic FinOps chargeback, and air-gapped supply-chain provenance.

The architectural bridge between these two poles is **Progressive Disclosure Over One Unified Kernel**: simple flows auto-orchestrate underlying enterprise entities (`Extension -> Secret -> Connection -> Model -> Deployment -> Route -> Key`) using verified defaults while exposing full granular separation-of-duties as organizational complexity grows.

## 3. Cross-Persona Tension Resolution Principles

| Apparent Persona Conflict | Anti-Pattern to Reject | Tanpopo Resolution Principle |
|---|---|---|
| **Solo User Simplicity (`PER-01`) vs Enterprise 7-Entity Governance (`PER-03`/`06`)** | Forking a "Lite" mode with a different database schema or weakening trust checks globally. | **Single Data Model + Atomic Setup Orchestrator:** Quickstart wizards populate the exact same `Adapter -> Secret -> Connection -> Model -> Deployment -> Route -> Key` tables inside one transaction with smart defaults, hiding multi-table plumbing until needed. |
| **Developer Debugging (`PER-02`) vs DPO Zero-Prompt Privacy (`PER-06`)** | Storing plaintext prompts in Postgres/ClickHouse or disabling diagnostics completely. | **Zero-Persistence Default + `RFC 9180 HPKE` Capsules:** Default stores `0` prompt bytes; on-error capsules seal asymmetrically to an offline Project Triage Public Key so Gateway nodes hold only the recipient public key (`[DESIGN_PROPOSAL]`). |
| **Community Extensibility (`PER-09`) vs Supply-Chain Security (`PER-05`/`06`)** | Allowing in-process `.so`/Python plugins or unverified auto-updates. | **Zero-Ambient-Authority `wazero` + Keyless OIDC + TUF + Lockfile:** Guests never receive raw secrets or sockets in Wasm memory (`BlindHostCredentialBroker`), and organizations enforce `min_plugin_trust` + `tanpopo.lock` SHA-256 pins. |
| **Ultra-High Throughput (`PER-03`) vs Pre-Request Budget Ceilings (`PER-07`)** | Dropping pre-request holds for async post-hoc spend logging (`LiteLLM`/`Bifrost`). | **Escrow-Backed Local Pod Budget Leases (`[DESIGN_PROPOSAL — TEEP-03]`):** Pre-deduct bounded slices in Valkey/PG (`atomic.Int64` hot path above `10%` Low-Water Mark; Valkey Lua below `10%`), preserving pre-hold budget bounds at `10,000+ RPS` (`HYPOTHESIS / UNVERIFIED`). |
