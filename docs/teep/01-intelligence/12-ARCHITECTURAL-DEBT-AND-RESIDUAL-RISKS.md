## 3. Deep Technical Root-Cause Investigations

### 3.1 `ARCH-OBS-01` — Organization-Wide Principal, Snapshot & Audit Scalability (`18` `O(N_orgs)` Loops + `7` Missing PG Indexes)
1. **Why `DEF-081` & `cd5e5dc5` Happened:** `bootstrap/token.go:518` inserts the instance `OPERATOR` with `principals.org_id = <first_org_id>` (`NOT NULL`), while PostgreSQL `FORCE RLS` under `SetOperatorRLSTx` (`is_instance_operator='true'`, `current_org_id=''`) **only reveals rows where `org_id IS NULL`**. Commit `cd5e5dc5` added sequential per-org `SetOrgRLSTx` loops, which restored correctness at `1–5` orgs while creating severe `O(N_orgs)` scaling walls.
2. **All 18 `O(N_orgs)` Loops Found Across RC9:**
   - *Hot Admin Auth & Unauthenticated Login DoS:* `iam/auth/local.go:1388` (`loadBindings` runs `2 * N_orgs` queries on **every Admin HTTP request** when `org_id IS NULL`), `local.go:815` (`LoginForOrg` runs `2 * N_orgs` on unknown email), `enrollment.go:301`, `local.go:551`.
   - *Cluster Thundering Herd:* `config/snapshot/manager.go:857` (`Manager.Refresh` executes **`2 + 7 * N_orgs` SQL queries across every CP+DP node** on every single `config_epoch` bump — `700,000` queries across `10` pods at `10^4` orgs, taking `~17.5 s` per node at `0.25 ms` RTT!).
   - *Containment, Reaper, Vault & Audit:* `killswitch/registry.go:365,1041,1210`, `installer/lifecycle.go:2803,3064`, `cmd/tanpopo/serve.go:1046` (`recordExtensionWebhookOutbox` called **twice** per quarantine!), `admin/http/extensions.go:1395`, `ops.go:1468`, `tenancy.go:1444` (`cleanupOrgRestrictedFKsTx`), `vault/store.go:1182`, `vkey/service.go:1130` (reaper tick), `rollup/aggregator.go:168`, and `audit/{verifier.go:258,blastradius.go:238}`.
3. **Seven Missing PostgreSQL Indexes (`0001_full_schema_rls_partitions.sql`):** `provider_connections(org_id, adapter_id)`, `org_extension_policies(pinned_installation_id)`/`(package_id)`, `emergency_kill_switches(org_id, active, triggered_at_ms DESC)` + principal FKs, `role_bindings(org_id, scope_type, scope_id, role_name)`, `webhook_event_outbox(org_id) WHERE dispatched_at_ms IS NULL`, `admin_change_requests` principal FKs, and `audit_events(chain_key, target_type, target_id, created_at_ms DESC)`.
4. **`audit_events` Serialization & False-Tamper Hazard:** `audit/logger.go:237,251` holds `pg_advisory_xact_lock` while probing **every monthly partition** (`ORDER BY seq_no DESC LIMIT 1` without `created_at_ms`), and `verifier.go` hardcodes `expectedSeq := 1` (meaning `PartitionManager.DetachAndDropExpired` triggers false `ALT-AUDIT-TAMPER` without `audit_partition_seals`!).
5. **Non-Atomic Two-TX Global Quarantine (`extensions.go:817-864`):** Splits `killSwitch.Trigger` (`TX1`) and `installer.Quarantine` (`TX2`), acquires locks in deadlocking `audit:SYSTEM -> hashtext(orgID)` order, leaves `TX1` committed if `TX2` hits non-OCC errors, and **omits `s.publishChange` Layer-1 Valkey broadcast**.
6. **Target Resolution (Preserving `100%` Tenant `FORCE RLS`):** Decouple `org_id IS NULL` `SYSTEM` operators + fix `loadBindings` (`O(1)`), add `iam_login_directory` blind HMAC index, persist `staged_by_principal_id` on `extension_installations`, add the 7 PG indexes + narrow `SECURITY DEFINER` affected-org lookup (`O(k_affected)`), introduce `audit_chain_heads` + `audit_partition_seals`, collapse quarantine into **1 atomic TX** with async outbox fan-out + direct Valkey broadcast, and convert `Snapshot.Refresh` to **incremental `config_changelog` delta reloads**.

### 3.2 `DEF-041` & `DEF-072` — Vault KEK Retirement Bug, Cold-Backup Resurrection & Cluster Node Loss
- **Newly Uncovered PG `FORCE RLS` Bug (`ops_lifecycle.go:196`):** `handleRetireMasterKEK` runs `SELECT COUNT(*) FROM org_encryption_keys WHERE kek_key_id = ?` under `withOperatorReadTx` (`current_org_id=''`), returning **`0` unconditionally on PostgreSQL** and allowing premature retirement of an active KEK! Additionally, `RetireKEK` is process-local only, `serve.go:359` mislabels `TANPOPO_MASTER_KEY_PREVIOUS` as `"kek_prev_0"` (breaking AAD unwrap for `"kek_v1"`), `vault rotate-kek` is SQLite-only, and `serve.go:547` deletes `cluster_nodes` on shutdown leaving `0`-DP-node clusters reporting `Ready/OK`.
- **`DEF-041` Gaps:** Phase 3 (`tx2`) failure after `ShredOrgDEK` leaves tenant VKeys and sessions active in RAM until manual retry; PG `postShredHook` is `pgStore.Ping`; and unwired `vault/kms` leaves pre-shred cold backups decryptable under static `TANPOPO_MASTER_KEY`.

### 3.3 `DEF-078` — FinOps Rollup Dead Code & Period Boundary Skew
- `rollup.NewAggregator` has `0` callers (`usage_rollups_hourly` empty); Chargeback defaults to unfiltered lifetime totals in UI and uses closed `<= toMs` (`finops.go:853`) vs Budget's half-open `< period_end_ms` (`:1118`); and cross-midnight SSE streams debit the prior period's `budget_ledgers` row while stamping `settled_at_ms` in the new period. **Fix:** Wire hourly/streaming rollups (adding exact/estimated request counts), unify half-open `[from, to)`, and stamp `billing_period_ref_ms` on `usage_settlements`.

### 3.4 `RR-001` — Four Root Causes of `.tpkg` Signing Digest Non-Reproducibility & Canonical Fix
1. **File-Set Divergence:** `builtin.NewCatalog()` (`extensions/official/assets.go:11`) packs `2–3` embedded files (`manifest.yaml`, `README.md`, `dist/*.wasm`), whereas `tanpopo plugin pack` (`testharness/pack.go:119`) packs `10–15` files including `cassettes/*`, `src/*`, and `adapter_test.go` (`fcd5f51d...` vs `cf69f96b...` on `@tanpopo/openai`).
2. **Windows `CRLF` vs POSIX `LF` Drift:** `catalog.go:199` embeds `README.md`/`manifest.yaml` verbatim without `\r\n` rejection or normalization (`fcd5f51d...` on LF vs `21d4f37a...` on CRLF vs `7717a1de...` in `7503607c`).
3. **Runtime `compress/gzip` Variance:** Re-running `gzip.BestCompression` at startup (`catalog.go:189`) depends on Go stdlib `compress/flate` bitstream details across Go versions.
4. **Wasm Build Drift:** `build-wasm.sh` invokes unpinned host `clang` without `-ffile-prefix-map` and omits `aws-bedrock`.
- **Canonical Fix (`CAP-117`):** Consolidate into one `internal/extension/tpkg` packer excluding `cassettes/`/`src/`/`*_test.go`, fail closed on `\r\n` in text assets, sign a Go-version-invariant **Canonical File-Tree Merkle Manifest (`tanpopo:tpkg-tree:v1`)** alongside deterministic pre-packed archives, container-pin `clang` (`+ aws-bedrock`), and enforce 3-OS (`linux`/`macos`/`windows`) SHA-256 parity in CI.
