### `DOM-01` — Universal AI Gateway (`8` Features · [Deep Spec](./03-FUNCTIONAL-DOMAINS/01-UNIVERSAL-GATEWAY-PROVIDERS-MODELS-AND-MEDIA.md))

- **Plain-Language Domain Summary:** Universal AI Gateway (DOM-01) is the front-door inference plane through which developer SDKs, IDE coding agents, and enterprise microservices invoke commercial and self-hosted AI models. Instead of forcing teams to rewrite applications into a lowest-common-denominator chat wrapper, it pairs drop-in compatibility for OpenAI (/v1/chat/completions, /v1/responses), Anthropic (/v1/messages), Google GenAI (/v1beta/models/*), specialized code/decision endpoints, and native vendor passthrough (/native/{dialect}/*) with uniform authentication, policy enforcement, cryptographic reasoning continuity, idempotency, and accurate streaming usage accounting.
- **Today in RC9 vs Proposed:** Frozen RC9 (ac9ae87a) provides a solid foundation on POST /v1/chat/completions, /v1/embeddings, /v1/rerank, payload-fingerprinted Idempotency-Key locking [SOURCE_VERIFIED], FMEA-01 clean SSE mid-stream error aborts without synthetic [DONE] markers [RUNTIME_VERIFIED], and X-Tanpopo-Usage-Accuracy HTTP trailers (DEF-083) [RUNTIME_VERIFIED]. However, top-level /v1/messages and /v1beta/models/* are absent (requiring /native/* prefixes), /v1/responses is a single-turn OpenAI-only shim unread by Tier-2 Wasm adapters [SOURCE_VERIFIED], multi-turn cryptographic reasoning signatures (thoughtSignature, signature, encrypted_content) are stripped on unified chat routes [SOURCE_VERIFIED], and /native/{dialect}/* blocks Azure ?api-version= query strings, rejects model-less GET requests, and mismatches leading-slash paths on AWS Bedrock Converse (DEF-048, FND-013) [SOURCE_VERIFIED].
- **Beginner-to-Enterprise Progression:** On Day-1, a solo self-hoster exports OPENAI_BASE_URL, ANTHROPIC_BASE_URL, or GEMINI_BASE_URL to point Claude Code, Cursor, or an existing SDK directly at Tanpopo with zero code changes and automatic usage tracking. As an organization scales to enterprise governance, teams progressively enable strict CT-08 zero-silent-downgrade validation, payload-fingerprinted Idempotency-Key deduplication for financial batch jobs, Zero-Data-Retention (ZDR) encrypted reasoning continuity, and explicit Virtual Key plane scoping.
