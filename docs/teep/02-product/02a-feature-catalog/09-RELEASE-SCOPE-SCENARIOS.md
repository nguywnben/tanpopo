# 09 — Coherent Release-Scope Scenarios for `TEEP-02B` Selection

- **Document ID:** `TEEP-02A-DOC-09`
- **Mission:** `TEEP-02A` — Proposed Master Feature Catalog
- **Governance Rule:** This document **does not lock product scope**. It presents four coherent, dependency-sound release-scope alternatives (`SCEN-A`, `SCEN-B`, `SCEN-C`, `SCEN-D`) so the Founder and Program Coordinator can select the authoritative scope at **`TEEP-02B`** (`DEC-CAND-02`). None of these scenarios optimize superficially for the earliest possible calendar launch, and none inflate priorities by marking every candidate `P0`.

---

## 1. Non-Negotiable Pre-`v1.0.0` Foundation Common to Every Scenario

Regardless of whether the Founder chooses `SCEN-A`, `SCEN-B`, `SCEN-C`, or `SCEN-D`, **no credible `v1.0.0` can ship** without first completing the **Foundational & Trust Floor**:
1. **All `P0` Foundational Remediations (`FND-001`..`010`, `012`..`014`, `016`, `017`, `020`):** Reproduce & fix the PostgreSQL `KEK` retirement `FORCE RLS` visibility hazard (`FND-001`), eliminate the `18` `ARCH-OBS-01` `O(N_orgs)` RLS loops + `7` missing PG indexes (`FND-002`, `ARCH-006`, `010`, `011`), resolve `RR-001` cross-OS `.tpkg` signing reproducibility (`FND-003`, `ARCH-015`), wire/resolve the `9` unwired subsystems & `4` `404` Admin endpoints (`FND-004`..`006`), fix atomic quarantine (`FND-008`), fix Day-0 unsigned `403` onboarding (`FND-010`), and close `PG-001`..`014` (`FND-017`).
2. **Core Performance Unlock (`ARCH-002`, `ARCH-004`, `ARCH-005`):** Pooled SSRF-safe keep-alive/HTTP2 upstream transports, split SQLite read/write + group-commit batching, and low-latency distributed budget admission.
3. **Priority Discipline Across the `153`-Feature Catalog:**
   - **`P0-Foundational` (`42 / 153` features, `27.5%`):** Core multi-protocol correctness, provider onboarding/probing, model catalog/discovery baseline, deterministic routing/deadlines, two-phase FinOps & rollover, baseline PII/Unicode guardrails, Vault/KMS safety, persistent admin auth + OIDC/SAML + PATs/VKeys, residency/audit/erasure integrity, dual-stack MCP, guided `< 90s` (`[HYPOTHESIS]`) `/setup` + `Doctor`, Console/CLI lifecycle parity, and Astryx shell polish.
   - **`P1-Enterprise-Core` (`70 / 153` features, `45.8%`):** Multi-level `OrgUnits`, `SCIM 2.0`, Policy-as-Code, secretless `WIF`, Four-Eyes UI, `FOCUS 1.1` chargeback, Prefix/KV affinity, Multi-Tier cache, Model Migration Advisor, What-If Traffic Replay, Blast-Radius Graph, Extension SDKs (`Go`/`Rust`/`TS`) + `11` categories + Safe Declarative Extension UI, Marketplace Discovery/Publishing + Private Git/Local/OCI sources + Air-Gap `.tpbundle`, In-App Notification Center + Email/Telegram/ChatOps + Setup Templates, Async Batch/Files, Config Revision History/Rollback, DB GitOps, Terraform Provider, Portable `SOLUTION_PACK`s, Product Update Center, and Security Advisories.
   - **`P2-Differentiator` (`38 / 153` features, `24.8%`):** Realtime Voice/Audio, Image/Video/Speech/OCR planes, Semantic Cache, Speculative Hedging, Signed FinOps Invoices + Cloud Billing Reconciliation, Analytical Warehouse Offload, Live `traces tail`, `HPKE` Flight Recorder, Reversible PII Tokenization, Sovereign Multi-Region Cells, Loopback Chaos Studio, Prompt Registry & Gateway Eval Cassettes/Shadow Canaries, K8s Operator, PR What-If CI Gate, and Multi-Instance Fleet Hub / Promotion Pipelines.
   - **`P3-Expansion` (`3 / 153` features, `2.0%`):** BlindBroker internal Vector/RAG enrichment subrequests (`FEAT-133`), Dual-Custody `SEC 17a-4` `WORM` Legal-Hold Archiver (`FEAT-137`), and Ephemeral CI `OIDC` Red-Team Eval Gate (`FEAT-094`).

## 4. Recommended Internal Milestone Structure (Applicable Under `SCEN-A`, `SCEN-B`, or `SCEN-D`)

Regardless of where the Founder places the external `v1.0.0` release cutline at `TEEP-02B`, internal execution should follow **five dependency-ordered milestones** so no feature is ever built atop unresolved `P0` debt:
1. **Milestone `M1` — Foundational Integrity, Throughput & Day-0 UX:** `FND-001`..`020`, `ARCH-002`..`012`, `ARCH-015`, Guided `< 90s` `/setup` + `Doctor`, Console/CLI lifecycle parity, High-Precision `RateCard` + Offline Model Pack + Discovery.
2. **Milestone `M2` — Universal Multi-Protocol Gateway, Guardrails & Caching:** Top-level `/v1/messages` & `/v1beta/*`, full `/v1/responses` + signature continuity, Prefix Affinity, Multi-Tier Cache, Multi-Stage Guardrails, Dual-Stack MCP (`2025` + `2026-07-28`) + Drift Classifier, LF `A2A v1.0.1`, Async Batch & Files.
3. **Milestone `M3` — Enterprise IAM, Governance, Sovereign Privacy & FinOps:** Persistent sessions + MFA, Multi-Org `OIDC` + `SAML 2.0` + `SCIM 2.0`, `OrgUnits`, Policy-as-Code, Secretless `WIF`, Four-Eyes UI, Cloud KMS, `GDPR` Salt-Shredding, `FOCUS 1.1` + Signed Chargeback Receipts.
4. **Milestone `M4` — Community Extension Platform, Declarative UI, Marketplace & Notifications:** `runtime.proto` `v1.1` `11` categories, `Go`/`Rust`/`TS` SDKs, Safe Declarative Console UI (`FEAT-104`), Public Marketplace + Private Git/Local/OCI sources + PG `.tpbundle`, In-App Notification Center + Email/Telegram/ChatOps + Setup Templates.
5. **Milestone `M5` — Pre-Flight Intelligence, Declarative GitOps, Update Center & Multi-Instance Fleet:** What-If Traffic Replay, Model Migration Advisor, 8-Layer Blast-Radius Graph, Config Revision History/Rollback, DB GitOps + Terraform + `SOLUTION_PACK`s, Product Update Center + Security Advisories (`DOM-26`), followed by Multi-Instance Fleet, Chaos Studio, Multi-Region Cells, and Realtime Media per the Founder's `TEEP-02B` scenario selection.
