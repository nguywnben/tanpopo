## Direct egress classification

The test runner's ordinary `curl` uses the configured network path and received HTTP 503 from the synthetic endpoint. A direct TCP connection to the same public host on port 443 returned `Network is unreachable`. Source inspection of RC5 [`internal/security/egress/ssrf_dialer.go`](../../internal/security/egress/ssrf_dialer.go#L1046-L1076) confirms `NewGuardedHTTPClient` deliberately sets `Proxy:nil` to prevent environment proxy settings from bypassing SSRF controls. The product's dispatcher therefore could not use the available proxy, and the delivery row recorded only a transport failure. No direct upstream response or successful HTTP delivery was observed. This is **BLOCKED by Cloud egress/runtime configuration**, not a Tanpopo defect; do not relax the SSRF guard to work around it. See [sanitized network result](../evidence/CP19-webhook-delivery-network-result.json).

## Results and limits

- **PASS:** real Console registration, enable, disable, delete, secret cleanup; retry-queued row cancellation; suppression of newly generated event delivery when disabled; synthetic project kill-switch trigger/clear UI.
- **BLOCKED:** actual success/4xx/5xx response handling, signature validation at receiver, response-body behavior, and real successful webhook delivery. This Cloud environment permits only proxy-routed general egress, while the guarded client intentionally bypasses it.
- No new product defect is confirmed in this phase. The generic transport failure is correctly distinguished from receiver HTTP status, and no external integration credential or spend was used.
- `DEF-034` remains **VERIFIED FIXED for the tested scoped revoke lifecycle**; CP19 adds queue cancellation and post-disable suppression evidence. It does not establish successful delivery semantics.
- **Residual coverage:** retry timing/backoff at longer intervals, exhaustion boundaries, concurrency, tenant isolation, PostgreSQL/Valkey, non-owner permissions, receiver signature verification, verified 2xx and explicit 4xx/5xx behavior, and actual direct egress are untested or blocked.
