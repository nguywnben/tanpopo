## Findings

- **DEF-043 Moderate, confirmed contract discrepancy:** built-in package reports a verified signature while source tracing shows the signer/root is local to the running instance's KEK-derived key. UI's `Publisher signature: Unsigned` contradicts the verified signature metadata and may conflate publisher signing with enterprise signing. No unauthorized code activation or exploit was shown; consent behavior held. [Standalone handoff](../reports/DEF-043-official-extension-provenance-misrepresented.md).
- **DEF-044 Low, confirmed UX/lifecycle defect:** active-package uninstall is offered, then rejected after user confirmation with an unhelpful message; quarantine is required first. Backend safety guard held. Quarantine switch persistence after removal is an unresolved observation. [Standalone handoff](../reports/DEF-044-active-extension-uninstall-action-fails.md).

## Facts, hypotheses, and uncertainty

**Facts:** UI labels, API state transitions, sanitized version metadata and screenshots are linked above. The staged package stayed inactive until explicit consent. Quarantine prevented immediate uninstall and subsequent safe removal succeeded. The active switch was explicitly cleared. No package inference/provider traffic occurred.

**Hypotheses:** The locally derived signature may be intended as embedded-binary local attestation, but that interpretation differs from the written offline release-root contract. The lifecycle menu may not filter actions by state, and the generic error may be a conflict-to-message mapping defect. Product design must decide whether quarantine kill switches outlive uninstall.

**Limits:** One built-in Anthropic adapter, one SQLite clone, bootstrap Operator/Org Owner, Chromium desktop, English/light mode. External/community packages, signature spoof/rejection, upgrade and rollback, package contract harness, sandbox execution/escape, blind credential broker, active lockfile serialization, active streams, other adapter packages, other browsers/locales/themes/viewports and PostgreSQL/Valkey were not exercised. Separate packaged RC5 artifact remains **UNVERIFIED**.
